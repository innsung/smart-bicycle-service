# 이용정보 CSV

서울 열린데이터광장의 **서울시 공공자전거 따릉이 이용정보(월별)** CSV를 이 폴더에 넣습니다.

지원하는 주요 컬럼은 다음과 같습니다.

- `RENT_NM` 또는 `대여일자`/`년월`
- `STATION_NO` 또는 `대여소번호`
- `STATION_NAME` 또는 `대여소명`
- `AGE_TYPE` 또는 `연령대`
- `USE_CNT` 또는 `이용건수`
- `MOVE_TIME` 또는 `이용시간(분)`

기존 `server/data/data_*.csv`는 대여 가능 수량 데이터이며, 2단계 재고 예측 학습에 사용합니다.
